# Semantic Model

This folder contains the semantic model documentation and DAX measures used for the Power BI report.

The semantic model is built on the Gold layer and follows a star-schema design.

## Tables

### Fact Table
- FactSales

### Dimension Tables
- DimDate
- DimCustomer
- DimProduct

## DAX Measures

Key measures include:

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value
- Current Year Sales
- Previous Year Sales
- Year-over-Year Sales Growth
