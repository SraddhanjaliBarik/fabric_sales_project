# Dataflow Gen2

Dataflow Gen2 was used to extract, transform, and load the sales data
into Microsoft Fabric.

## Activities

- Extracted source sales data
- Cleaned and transformed the data
- Changed data types
- Removed duplicate records
- Handled missing values
- Loaded the transformed data into the Lakehouse

## Data Flow

Source Data
→ Dataflow Gen2
→ Transformations
→ Lakehouse

## Tools

- Microsoft Fabric
- Dataflow Gen2
- OneLake
- Lakehouse
